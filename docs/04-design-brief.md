# 디자인 브리프 — 클로드 디자인 전달용

작성 9/27. 이 문서 전체를 클로드 디자인에 첨부하거나 붙여넣고, 맨 아래 「프롬프트」를 첫 메시지로 보낸다.

---

## 1. 프로젝트

- **무엇:** 결혼을 갤러리 전시 형태로 여는 두 사람의 초청·안내 사이트. 모바일 웹.
- **전시명:** 「어쩌다 결혼」
- **두 사람:** 김우진 · 문예인
- **일시:** 2026년 12월 5일 토요일. 가족 12:30–14:00, 일반 하객 14:00–19:00 (1시간 슬롯 5개, 슬롯당 20명)
- **장소:** 서울 강동구 양재대로 1399 (대관 공간 이름 "플랫1399"는 보조 정보. 강조하지 않는다)
- **전시 내용:** 두 사람의 사진 위주 + 추억이 담긴 오브제(레고, 퍼즐 등)
- **톤:** 전시 안내 7 : 청첩장 3. 모바일 청첩장처럼 보이면 실패. AI가 만든 템플릿처럼 보여도 실패.
- **비주얼 방향:** 화이트 + 블랙 기본. 두 사람이 좋아하는 자연 요소(바다, 풀)가 포인트로 들어간다.
- **레퍼런스 사이트:** (클라이언트가 추가) ______

## 2. 하객이 이 사이트에서 해야 하는 것

1. 언제, 어디서 열리는지 안다.
2. 참석 여부와 방문 희망 시간대를 두 사람에게 전한다.
3. 종이 초대장을 우편으로 받거나(주소 입력), 모바일 티켓을 받는다.

## 3. 하드 제약 (디자인이 이 안에서 나와야 한다)

- **폭:** 최대 500px. 그 이상은 가운데 정렬. 기준 기기 iPhone 17 / 18, 폭 390–430px.
- **접속 경로:** 카카오톡 인앱 브라우저가 1순위, iOS Safari 2순위.
- **성능:** LTE 첫 화면 3초 이내, 전체 전송량 1.5MB 이하. 3D·WebGL·대용량 영상 금지. 스크롤 연동 페이드/슬라이드, 마스크, 선이 그려지는 정도의 모션까지 허용.
- **다크 모드 없음.** 라이트 단일.
- **폰트:** Pretendard Variable 기본. 세리프를 쓰려면 무료 웹폰트여야 한다.
- **구현 스택:** React + CSS 변수 토큰 + `motion`(Framer Motion). 디자인 결과물은 이 형태로 옮겨 구현한다.

## 4. 현재 섹션 순서와 내용

| # | 섹션 | 내용 | 상태 |
|---|---|---|---|
| 00 | 인트로 | 전시명, 두 사람 이름, 날짜·시간·주소. 첫 화면 | 텍스트만 있음. 상단 60%가 비어 있어 사진/자연 요소 자리 필요 |
| 01 | 전시 형태 | "이건 결혼식이 아니라 전시입니다"를 자연스럽게. 사진 + 오브제 전시임을 안내 | 미구현 |
| 02 | 장소·시간 | 날짜 크게, 12:30–19:00 타임라인 바(가족/자유 관람 구간이 그려짐), 주소, 네이버·카카오·주소복사 버튼, 주차 안내(미정) | 구현됨 |
| 03 | 전시 구성 | 케이터링(음료+핑거푸드), 축의금 대신 사진 판매 → 수익은 갈라파고스 탐험(신혼여행). "식사 없음", "축의금 안 받음"을 직접 쓰지 않고 전시 구성 안내처럼 보여줄 것 | 미구현 |
| 04 | RSVP | 참석 여부 → 시간대 → 이름·번호·인원 → 종이/모바일 → 주소 → 완료 | 구현됨. 단계형 폼 |
| — | 티켓 페이지 | `/t/코드`. 이름·시간·장소가 들어간 모바일 티켓. 이미지 저장 | 구현됨. 캔버스 |

## 5. RSVP 흐름 (그대로 유지)

```
참석 여부 ─ 참석 → 시간대(5개, 잔여 5명 이하만 표시, 마감은 비활성) → 이름·휴대폰·인원(1–6)
         │                                                   → 종이 초대장 → 주소(우편번호 검색)+상세 → 완료(우편 안내)
         │                                                   → 모바일 티켓 → 완료(티켓 열기)
         └ 불참 → 이름 + 한마디(선택) → 완료(감사)
```
- 가족 링크(`?family`): 시간대 단계 없음, 12:30–14:00 고정.
- 마지막 슬롯 잔여, 마감 표시가 있다.
- 입력 필드는 16px 이상(iOS 확대 방지), 버튼 높이 44px 이상.

## 6. 카피 소재 (문구는 초안, 디자인에서 제안해도 됨)

- 갈라파고스: 신랑의 메일 주소에는 항상 1859가 붙어 있다. 찰스 다윈 『종의 기원』 출간 연도. 다윈이 진화론의 영감을 얻은 땅을 밟기를 고대한다. → 사진 판매 섹션의 핵심. "1859"를 시각 요소로 쓸 수 있다.
- 케이터링: 음료와 핑거푸드가 마련되어 있다.
- 관람: 정해진 순서 없음. 고른 시간에 와서 머무르고 싶은 만큼.
- 개인정보: 주소와 번호는 초대장 발송에만 쓰고 전시가 끝나면 지운다.
- 혼주 표기 없음. 연락처 노출 없음.

## 7. 현재 임시 토큰 (`src/styles/tokens.css`)

```
배경 #f7f6f2 · 표면 #ffffff · 잉크 #141414 · 잉크2 #5a5a57 · 잉크3 #9a9994 · 선 #e3e1da
바다 #2f5d6b · 풀 #6b7f4a
디스플레이 clamp(2.4rem, 11vw, 3.6rem) · h1 1.75rem · h2 1.25rem · 본문 1rem · small 0.8125rem · micro 0.6875rem
간격 4/8/12/16/24/32/48/72/112 · 거터 24px · 라운드 2px
모션 ease cubic-bezier(0.22,1,0.36,1) · 180/360/720ms
```
이 값은 전부 교체 가능하다. 구조(이름)는 유지하면 옮기기 쉽다.

## 8. 자료

- 두 사람 사진, 전시장 사진, 오브제 사진: **아직 없음.** 디자인에서는 플레이스홀더 비율만 정해달라.
- 실물 초대장 디자인: 없음. 사이트가 먼저.

## 9. 돌려받고 싶은 것 (이 형태여야 코드로 옮길 수 있다)

1. **토큰 표:** 색(이름 → 값), 타입 스케일(크기·행간·자간·굵기), 간격, 라운드, 모션 곡선·시간. 7번 구조에 맞춰.
2. **섹션별 레이아웃 스펙:** 390px 기준 화면 목업 + 여백·정렬 수치. 사진 자리는 비율과 처리(풀블리드/여백/마스크)만.
3. **모션 스펙:** 각 요소가 언제(스크롤 진입/탭/단계 전환) 어떻게(속성, 시간, 지연, 곡선) 움직이는지 표로. 성능 제약 안에서.
4. **RSVP 컴포넌트:** 선택 버튼(기본/선택/비활성/마감), 입력 필드(기본/포커스/오류), 주 버튼, 단계 전환 방식.
5. **티켓:** 1080×1620 세로 이미지로 저장되는 티켓의 레이아웃. 이름·인원·날짜·시간·주소·코드가 들어간다.
6. 가능하면 HTML/CSS 프로토타입. React로 옮기기 쉽다.

- 전시명 「어쩌다 결혼」, 김우진 · 문예인. 2026.12.5 토, 14:00–19:00 (가족 12:30–14:00). 서울 강동구 양재대로 1399.
- 톤: 전시 안내 7 : 청첩장 3. 모바일 청첩장 템플릿처럼 보이면 안 되고, AI 티가 나도 안 돼.
- 비주얼: 화이트+블랙 기본, 바다·풀 같은 자연 요소를 포인트로. 레퍼런스: [링크]
- 제약: 최대 폭 500px, 기준 390px. 카카오톡 인앱·iOS Safari. 라이트 단일. 3D/WebGL/영상 금지, 가벼운 스크롤 모션만. Pretendard 기본.

먼저 방향 2안(무드보드 수준)을 보여주고, 내가 고르면 전체를 진행해.
